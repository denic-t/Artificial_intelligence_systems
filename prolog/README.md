# Семейное древо на языке Prolog

## Задание

- Составить российское семейное древо из 30 человек.
- Для каждого человека записать факт `birth` только с годом рождения.
- Для умерших записать факт `death`, для состоящих или состоявших в браке - `marriage`, для разведённых - `divorce`.
- Написать 30 правил, например `alive(X, Date)`, который проверяет, жив ли человек `X` на дату `Date`, и `single`.
- В отчёте привести дерево, факты с комментариями и не менее 10 запросов со скриншотами выполнения.

Пример стиля кода от преподавателя:

```prolog
parent(alexandrII, alexandrIII). % predicate
parent(alexandrII, vladimir).
parent(alexandrIII, nikolaiII).
sibling(Y, Z) :- parent(X, Y), parent(X, Z), Y \= Z.
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
```
